**What is _Mutation_ in data type ?**

- "Mutable" means "changeable". Mutation means a change in the original code or data. If something is "immutable", it can never be changed. Note: Primitive values is immutable. They're read-only. For example, **let num = 5; let str = "Hello"; let bool = false** . But the Non-primitive data type is mutated, For example : **array, object**
